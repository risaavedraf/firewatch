That section states the rule's arithmetic with the batch's own readings — the five canonical variables `temperatura`, `humedad_relativa`, `viento`, `cobertura_vegetal` and `incendios_historicos`, each with value and contribution — and never causality or a forecast. A factor without a reading is named as having none; it is not hidden, filled in or charged.
  - **`R3` — synthetic disclosure, verbatim:** «se cargan como fixture **declarado como sintético en la propia interfaz y en el PDF**, nunca solo en un comentario». `D-A` is resolved — synthetic fixtures are permitted, the label is not relaxed — so the ficha carries the visible disclosure text the page already shows for a `demo: true` batch, in extracted text and not only in metadata or a comment.
  - **Content and provenance in one document:** zone and commune, publication date with `data_status`, risk level, the `R2` calculation section, the preventive recommendations already composed read-only by [`../../frontend/src/domain/recommendations.ts`](../../frontend/src/domain/recommendations.ts) (PM-18; suggesting creates no action), and the commune map drawn as vector PDF graphics from the existing client projection ([`../../frontend/src/components/map/projection.ts`](../../frontend/src/components/map/projection.ts)).
  - **Reproducible for identical inputs:** the generator is a pure function of its snapshot — no clock read, no random or `/ID` bytes, no unordered-map iteration — so the same input yields the same bytes and the same extracted text.
  - **Tests compare extracted text, not raw file bytes:** the assertions read the content operators back and compare what the document must say — headings, variables, values, the `R2` label, the `R3` disclosure, the date — so a layout change cannot fail the suite while a content regression cannot hide behind it.
  - **Zero external runtime or CDN dependency:** `script-src 'self'` and `img-src 'self'` in [`../../backend/services/gateway/internal/handler/gateway.go:186`](../../backend/services/gateway/internal/handler/gateway.go) forbid a CDN-loaded PDF library, a remote font or a fetched image. The generator is in-repo TypeScript writing PDF 1.4 bytes and embedding the map as path operators.
